# Техническая проверка Android-мультиплеера SFS

Дата проверки: 2026-11-12  
Целевая версия: Spaceflight Simulator 1.6.00.22 на Android

## Результат проверки

В официально документированном загрузчике модов SFS для Android доступны **моды ресурсов** (asset mods): наборы деталей, текстуры и другие поддерживаемые игровые ресурсы. Кодовые моды, которые добавляют поведение через C#/.NET DLL, документированы только для настольных версий Windows/macOS.

Это означает, что обычный сетевой мод нельзя сейчас собрать как DLL и просто положить в папку Mods на Android. Сетевой мод должен не только обмениваться пакетами, но и получать состояние собственной ракеты и создавать/обновлять объекты других игроков в сцене игры. Публично документированной Android-точки расширения для этих действий в проверенных материалах не найдено.

Сведения руководства о поддержке платформ: на Android доступны asset mods; code mods (DLL) указаны для desktop. Наличие папки Mods на Android само по себе не означает возможность запускать произвольный код.

## Требования к настоящему мультиплееру

Для цели проекта недостаточно отдельного чата или приложения-компаньона. Интеграция должна уметь:

1. Получать координаты, угол поворота и скорость ракеты локального игрока.
2. Передавать состояние по локальной сети с идентификатором игрока и временем обновления.
3. Получать состояния остальных 1–3 игроков.
4. Создавать и обновлять визуальные копии ракет в игровом мире SFS.
5. Обрабатывать выход игрока, задержки и потерю соединения.

## Что делать дальше

- Не собирать фиктивный APK: он не сможет отобразить чужие ракеты внутри SFS без доступа к игровому процессу.
- Следить за появлением официальной Android API/поддержки code mods либо подтверждённого загрузчика кода для этой версии.
- Если появится поддерживаемая точка интеграции, первым сетевым этапом станет LAN-прототип на двух устройствах, затем синхронизация состояния ракеты и только потом тест 3–4 игроков.

## Текущий статус

Это исследовательский этап, не готовый мод. В репозитории пока нет APK и нет работающей интеграции с игрой. Не устанавливайте неизвестные APK и не заменяйте оригинальную игру модифицированной сборкой.
