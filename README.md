# SFS Multiplayer Android — исследовательский проект

Цель проекта: проверить, можно ли реализовать сетевую игру для **Spaceflight Simulator 1.6.00.22 на Android**, чтобы 2–4 игрока в одной Wi‑Fi-сети видели ракеты друг друга непосредственно в игровом мире.

## Статус

**Этап 0 — проверка технической возможности.** Рабочего мода и APK пока нет.

По опубликованному руководству по моддингу SFS, мобильная версия 1.6 поддерживает моды ресурсов (детали, текстуры и планеты), но не поддерживает кодовые моды DLL. Поэтому обычный PC-мод с сетевым кодом нельзя просто перенести на Android.

Источник: [SFS Modding Guide — Introduction](https://kojamori.github.io/SFS-Modding-Guide/).

## Цель первой версии

- 2–4 игрока;
- подключение через одну локальную Wi‑Fi-сеть;
- создание комнаты и подключение к ней;
- передача состояния ракеты (координаты, ориентация и скорость);
- отображение чужих ракет **внутри игрового мира SFS**.

## Технические этапы

1. Изучить доступные Android-механизмы моддинга SFS 1.6.00.22.
2. Найти поддерживаемую точку интеграции с игровым процессом. Без неё отдельное приложение не сможет рисовать ракеты внутри SFS.
3. Сделать минимальный сетевой прототип для локальной сети.
4. Проверить синхронизацию состояния двух тестовых ракет.
5. Только после успешной проверки интеграции собирать установочный пакет.

## Важное ограничение

Отдельное Android-приложение может обмениваться данными по Wi‑Fi, но само по себе не может добавлять объекты в сцену SFS. Не считать сетевой чат, обмен чертежами или внешний просмотрщик готовым внутриигровым мультиплеером.

## Сборка

Сборка APK пока не настроена: сначала требуется подтвердить способ безопасной и совместимой интеграции с Android-версией игры. Не устанавливайте неизвестные APK и не заменяйте оригинальную игру модифицированными сборками.
